text-editing

Writing and editing text in place.

19 terms across 4 categories · all tags

component

  • Bubble toolbar

    A small formatting bar that appears floating over a text selection and disappears when the selection is dropped.

  • Code editor

    A text area specialised for code, with a gutter of line numbers, syntax colouring and a caret that understands indentation.

  • Diff viewer

    The view that puts two versions of a text against each other, side by side or interleaved, marking every line added, removed or changed and aligning what did not.

  • Inline edit

    Text that reads as plain content until you click it, at which point it becomes an input in the same place with save and cancel.

  • Prompt input

    The composer at the bottom of an assistant interface: a growing text area with attachment, model and send controls attached to it.

  • Rich text editor

    An editing surface that shows formatting as it will appear rather than as markup, so what the writer sees is close to what readers get.

  • Rich text toolbar

    The strip of formatting controls above or beside an editor, whose buttons report their state from wherever the caret sits.

  • Tag input

    A field that turns each entry into a removable tag sitting inside the field, with the caret waiting after the last one.

  • Text area

    A multi-line text box, usually resizable, for input that will not fit on one line: a comment, a description, an address, a note.

  • Text field

    A single line box for typed input, carrying a label, an optional hint, and the error message shown when what was typed does not pass.

  • Three-way merge

    Three versions on screen at once, mine, theirs, and the ancestor they both came from, with the result edited underneath so a conflict is decided rather than guessed.

pattern

  • Autosave

    Persisting the reader's work continuously without a save action, usually with a quiet status line reporting when the last save happened.

  • Inline autocomplete

    Completing the reader's text inside the field itself, with the guessed remainder selected so the next keystroke replaces it.

  • Mention autocomplete

    Typing a trigger character inside a text field to open a filtered list of people or objects, inserting the chosen one as a linked token.

  • Slash command

    Typing a forward slash in a composer to open a menu of actions, where choosing one runs it rather than inserting the words into the message.

  • Unsaved changes guard

    Warning the reader that edits will be lost before a navigation or close is allowed to proceed, and offering to save or discard first.

interaction

  • Caret

    The blinking marker showing where typed text will be inserted, moved by clicking, by arrow keys, or by dragging on touch.

  • Selection handle

    The draggable grip at each end of a touch text selection, used to widen or narrow the range a finger cannot adjust precisely.

color

  • Syntax highlighting

    Colouring code by what each token is, keyword or string or comment or name, so the structure and the typo are visible before a line has actually been read.
