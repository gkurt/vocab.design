aesthetic

A named visual style, with a period and a set of moves.

65 terms · all categories

Tagged in this category: retro37 · depth19 · illustration19 · editorial12 · grids5 · platform-registers4 · theming3 · media2 · spacing2

  • Acid graphicsalso acid design, acid house revival, acid brutalism, rave graphics

    A 2020s rave revival style of chrome and liquid 3D objects, warped and stretched lettering, clashing saturated colour on near black, smileys, globes, and wireframe motifs.

  • Afrofuturismalso Afro-futurism, Afrofuturist design

    A style that pictures technology through the African diaspora, combining cosmic imagery, textile and mask pattern, gold and indigo, and geometric ornament used structurally.

  • Anti-designalso ugly design, intentionally ugly web design, anti-aesthetic, anti-polish, raw aesthetic, Internet Ugly

    A deliberately awkward style that breaks layout, type, and color conventions so the interface reads as a statement rather than as a polished product.

  • Aquaalso lickable UI, gel buttons, candy buttons, gumdrop buttons

    Apple's early Mac OS X look of glossy blue gel buttons, pinstripes, gumdrop window controls, and a pulsing default button.

  • Art Decoalso deco style, Streamline Moderne, Gatsby style

    A 1920s luxury style of strict symmetry, stepped and fanned geometry, strong vertical emphasis, metallic gold on deep colour, and high contrast display capitals.

  • Art Nouveaualso nouveau style, Jugendstil, whiplash line

    A turn of the century style of whiplash curves, botanical line ornament, muted jewel tones, and lettering drawn to fit the frame rather than set on a grid.

  • Aurora UIalso aurora gradient, northern lights background, blurred blob background, glow background

    A style whose background is built from heavily blurred color blobs that glow and drift like the northern lights behind the content.

  • Bauhaus stylealso Bauhaus, Bauhaus revival, Bauhaus web design

    A style reduced to primary red, yellow, and blue on off-white, elementary circles, triangles, and squares, and undecorated sans serif type.

  • Biophilic designalso biophilic web design, biophilia in design, nature-inspired UI, organic UI, biomimetic design

    A style that borrows from the natural world on purpose, using earthy greens and clays, organic silhouettes, botanical imagery, and slow ambient motion to make a screen feel less mechanical.

  • Brutalist web designalso web brutalism, brutalism, raw HTML aesthetic, default browser look, brutalist typography, anti-grid brutalism, sports brutalism

    A raw style that leaves the document showing: system or monospace type, default link blue, hard borders, and no decoration beyond structure.

  • Cassette futurismalso cassette punk, tape futurism, analog futurism, used future

    The analog future of late 1970s science fiction: beige and putty plastic, chunky toggles and rocker switches, amber or green CRT readouts, and monochrome bitmap type.

  • Claymorphismalso clay UI, claymorphic design, play-doh UI, puffy 3D buttons

    A soft style where controls look inflated from clay: pastel fills, very large corner radii, an inner highlight, and a tinted drop shadow.

  • Constructivismalso Russian constructivism, constructivist design, Soviet poster style

    A 1920s poster language of diagonal bars and blocks, red and black on off-white, photomontage, and heavy sans capitals set on a strong angle.

  • Corporate Memphisalso Alegria, big tech illustration, humans of flat, flat art, blob people

    The flat vector illustration style of bright, faceless people with long bendy limbs and small torsos that spread across tech marketing from 2017.

  • Cyberpunk UIalso cyberpunk style, cyberpunk aesthetic, neon dystopia UI, hacker UI

    A dystopian sci-fi interface style: near-black surfaces, one or two toxic neon accents, monospace all-caps labels, clipped corners, and scanline or glitch noise laid over the top.

  • De Stijlalso neoplasticism, Mondrian style, Mondrian grid

    A style built only from black rules, rectangular fields, and the three primaries on white, arranged asymmetrically with no curves and no diagonals.

  • Digital collagealso collage aesthetic, cut-out collage, mixed media, scrapbook aesthetic, paper cut-out style

    A composition assembled from cut-out photography, torn paper edges, scanned texture, and type set at odd angles, so the page reads as pasted up rather than laid out.

  • Digital rainalso matrix rain, matrix code, falling code

    Columns of glyphs falling and trailing away, green on black, the Matrix screen quoted so often that it now reads as shorthand for a computer thinking.

  • E-ink aestheticalso paper UI, e-paper UI, e-ink UI, paper-like interface, 1-bit UI

    A paper-like style built for or borrowed from electronic ink: near-white ground, pure black text, hairline rules, no shadows or gradients, and paged navigation.

  • Editorial web designalso editorial design, editorial style, magazine style web design, print-inspired web design

    A style that borrows print magazine craft for the screen: a visible column grid, display type at poster scale, pull quotes, rules, and captioned images set into the text.

  • Fictional user interfacealso FUI, fantasy user interface, futuristic user interface, film user interface, sci-fi HUD, HUD style

    The screen graphics style invented for film, television, and games: dense readouts, targeting reticles, and animated telemetry that look computational without computing anything.

  • Flat 2.0also semi-flat design, almost flat design, flat design 2.0, near-flat

    Flat design with the depth cues put back in small doses: soft shadow, subtle gradient, and hover feedback that show what can actually be clicked.

  • Flat designalso flat UI, flat design 1.0, 2D interface style

    A style that strips away depth cues, using solid fills, sharp edges, and bold color instead of shadow, gradient, bevel, or texture.

  • Frutiger Aeroalso Web 2.0 gloss, Aero aesthetic, glossy 2000s, bubbles and grass aesthetic, Neo-Aero

    The mid 2000s look of glossy gradients, bubbles, water, bright skies, and clean humanist type, named after the typeface and Windows Aero.

  • Frutiger Metroalso Vectordelia, flat Frutiger Aero, vector metro, vector vomit

    The flat vector cousin of Frutiger Aero: gradient color blocks, bloom and glow, silhouetted figures, swooshes and abstract flourishes, without the glossy water and grass.

  • Glassmorphismalso frosted glass, acrylic

    A style where surfaces are translucent and blur what is behind them, separated from the backdrop by a hairline edge and a soft shadow.

  • Glitch aestheticalso glitch art, RGB split, chromatic aberration, datamosh

    A look that fakes signal failure with colour channel offset, torn scan bands, and jitter, used for emphasis or as a whole visual identity.

  • Grunge designalso grunge typography, punk grunge, distressed style, zine aesthetic

    A 1990s style of torn and photocopied texture, overlapped and cut type, off-grid layout, and dirty muted colour, where legibility is traded for emotional pitch.

  • Hand-drawn UIalso sketchy UI, rough style, wireframe aesthetic, lo-fi look, Excalidraw style

    A style whose lines wobble as if sketched by hand, used to signal that a diagram or wireframe is provisional rather than finished.

  • Hyperreal 3Dalso 3D hyperrealism, hyperrealistic render, photorealistic 3D, CGI hero

    Rendered objects pushed past photographic realism, with physically based materials, sharp specular detail, and studio lighting, floated over an otherwise plain interface.

  • Isometric illustrationalso isometric art, 2.5D illustration, axonometric, isometric UI

    Art drawn on a fixed axonometric grid so depth reads without perspective, with parallel edges and no vanishing point.

  • Kawaii UIalso kawaii, cute UI, mascot UI, pastel cute style

    A cute style of pastel fills, rounded everything, oversized eyes and blush marks, sticker and mascot characters, and hand-lettered or bubbly rounded type.

  • Liquid Glassalso glass effect, iOS 26 glass, Apple glass design

    Apple's 2025 material where controls float as a translucent layer that refracts what is behind them and reshapes fluidly as content moves underneath.

  • Low polyalso low-polygon, lowpoly, faceted 3D, polygonal illustration

    A 3D style that keeps the polygon count low enough to see, so surfaces read as faceted triangles under flat shading instead of smooth curves.

  • Material 3 Expressivealso M3 Expressive, expressive design, Android 16 design

    Google's 2025 update to Material 3: springier motion, emphasized typography, updated dynamic colour themes, and responsive components that stretch to hug the display.

  • Material Youalso dynamic color, Material 3, Monet, wallpaper theming, wallpaper-based theming

    Google's personalization layer where the system derives an app's entire color scheme from the user's wallpaper, so every app shifts together.

  • Maximalismalso maximalist web design, more is more, cluttercore, dopamine design, Gen-Z chaos

    A style that fills the screen on purpose with layered color, pattern, and type, treating abundance rather than restraint as the message.

  • Memphis designalso Memphis style, Memphis Milano, squiggle and confetti, 80s postmodern

    The 1980s Memphis Group look of clashing pastels, squiggles, confetti dots, and terrazzo shapes scattered across a layout.

  • Metroalso Modern UI, Windows Phone design, Microsoft design language, tile UI

    Microsoft's typography led design language of flat coloured tiles, large light headings, and motion used in place of chrome, shadow, and texture.

  • Micaalso mica material, Mica Alt, wallpaper-aware background

    Fluent's opaque app background material, subtly tinted with the user's desktop wallpaper colour and going neutral when the window loses focus.

  • Mid-century modernalso MCM, atomic age style, Googie

    A 1950s and 60s style of muted mustard, teal, and burnt orange, tapered organic shapes, textured paper grounds, and friendly geometric sans type.

  • Minimalismalso minimalist web design, minimal UI, reductive design, clean UI, exaggerated minimalism, less is more

    A style that reduces an interface to one typeface, one accent color, and generous empty space, letting whitespace rather than ornament carry hierarchy.

  • Neo-skeuomorphismalso modern skeuomorphism, tactile UI, skeuomorphism revival, new skeuomorphic

    The current return of depth and material to interfaces, using restrained texture, shadow, and highlight instead of literal leather, metal, and felt.

  • Neubrutalismalso neobrutalism, neo-brutalism, new brutalism, hard shadow style, sticker UI

    A loud style built from thick black outlines, saturated flat color, square corners, and hard offset shadows with zero blur.

  • Neumorphismalso soft UI, neumorphic design

    A style where controls look extruded from or pressed into one background colour, shaped only by soft light and shadow.

  • New Wave designalso Swiss punk, New Wave typography, Weingart style, postmodern typography

    The postmodern break from Swiss order: stair-stepped rules, diagonal and letter-spaced type, weights mixed inside a word, and text reversed out of bars.

  • Pixel art UIalso 8-bit UI, bitmap UI, pixel UI, pixelated interface, pixel art

    An interface drawn on a visible pixel grid, with bitmap type, hard aliased edges, and icons kept at their original low resolution.

  • Pop art stylealso pop art, comic style, Ben Day style, Lichtenstein style

    A comic and advertising style of flat primary color, heavy black outlines, printed dot shading, speech balloons, and bold condensed capitals.

  • Psychedelic stylealso psychedelia, 60s poster style, trippy style

    A 1960s poster style of vibrating complementary color, warped and interlocking lettering that fills its own shape, kaleidoscopic symmetry, and liquid distortion.

  • Retro film aestheticalso vintage analog, analog nostalgia, film look, 35mm look, polaroid look, light leak

    A treatment that makes digital imagery look shot on film, adding grain, halation, light leaks, faded contrast, dust, and sometimes a corner date stamp.

  • Retro web designalso 90s web design, retro UI, nostalgia web, Windows 95 UI

    A style that rebuilds the early desktop web on purpose: beveled window chrome, pixel and system type, garish color, and animated banners.

  • Retro-futurismalso retrofuturism, retro-future, yesterday's tomorrow

    A style that pictures the future the way an earlier decade pictured it, so the technology shown is advanced but the type, color, and hardware belong to the past.

  • Risograph stylealso riso print, riso aesthetic, misregistration style, spot color print look

    A print-inspired look of two or three flat spot colors that misregister slightly and show grain, imitating a riso duplicator.

  • Skeuomorphismalso skeuomorphic design, realistic UI, skeuomorph, textured UI

    A style that makes interface elements imitate real objects and materials, using leather, metal, paper, and glossy highlights so their purpose reads as familiar.

  • Solarpunkalso solar punk, eco-futurism, utopian solarpunk

    An optimistic ecological future style of daylight palettes, plant growth over structure, stained glass colour, art nouveau curves, and visible solar and wind technology.

  • Spatial UIalso spatial design, visionOS UI, XR interface, 3D UI, mixed reality UI

    Interface designed to sit in three dimensional space, where panels are made of a system glass material and hierarchy is carried by depth rather than by colour.

  • Steampunkalso steampunk style, Victorian futurism, dieselpunk

    A Victorian industrial style of brass, riveted plate, wood, and leather, with gauges, cogs, and valve controls standing in for ordinary interface widgets.

  • Swiss stylealso International Typographic Style, Swiss design, grid system design, Helvetica style, Swiss modernism, Swiss modernism 2.0

    The Swiss modernist system of a strict grid, flush left sans serif type, asymmetric layout, and objective photography, still the base of clean UI layout.

  • Synthwavealso outrun, retrowave, neon 80s, SynthWave '84

    A neon 1980s look built on sunset gradients, glowing perspective grids, and chrome type, close to vaporwave but sincere rather than ironic.

  • Terminal aestheticalso TUI aesthetic, console UI, monospace UI, hacker aesthetic, green screen

    A look borrowed from the command line: monospace type on a fixed character grid, a block cursor, and green or amber text on black.

  • Vaporwavealso vapourwave, aesthetic, mallsoft, 80s 90s nostalgia UI

    A retro internet look of magenta and cyan gradients, grid horizons, Japanese type, statuary, and 90s desktop chrome used ironically.

  • Vernacular webalso GeoCities aesthetic, old web, web 1.0, amateur web, under construction web

    The amateur homepage look of the GeoCities era: tiled backgrounds, sparkle GIFs, under construction signs, midi music, and hit counters.

  • VHS aestheticalso VHS look, tape aesthetic, analog horror look, camcorder overlay

    A look that imitates a worn videotape: tracking bands, smeared color bleeding past edges, interlace comb artifacts, and burned-in timecode or REC overlays.

  • Windows Aeroalso Aero Glass, Aero, Windows 7 glass, glass window borders

    The Windows Vista and 7 look built on translucent glass window frames, soft outer glows, reflections, and animated window transitions.

  • Y2K aestheticalso Y2K futurism, millennium aesthetic, chrome aesthetic, cybercore, liquid chrome, 3D chrome

    The turn of the millennium look of chrome type, bubble shapes, translucent plastic, and lens flares, revived as a web and app style.
