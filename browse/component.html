  • Accordionalso expansion panel, collapsible list

    A stack of headers, each expanding to reveal its own section of content.

  • Action listalso action menu, command list, menu list

    A vertical list of commands with icons, descriptions and dividers, the shared body used inside menus, panels and side sheets.

  • Action sheetalso action sheets, bottom action menu, option sheet

    A modal list of choices that slides up from the bottom of a phone screen in response to something you just did, with cancel at the end.

  • Agenda viewalso schedule view, up next

    The same events as a chronological list grouped by day, so the next thing is at the top instead of somewhere inside a grid.

  • Alert dialogalso alertdialog, alert modal

    A dialog that interrupts the flow to demand acknowledgement or confirmation of a consequential action before anything else can continue.

  • App baralso top app bar, application bar

    The persistent bar across the top of an application carrying its title, navigation, and primary actions.

  • App shortcutalso home screen quick action, dock menu, quick action, launcher shortcut, long press shortcut

    A short menu of app actions hung off the app icon itself, opened by a long press or a secondary click before the app is even running.

  • Attribute editoralso tag editor, key value editor, repeater, dynamic form rows, field array

    A repeating row of key and value fields with add and remove controls, used for tags, headers and other open ended pairs.

  • Avataralso persona, profile picture, user pic, gravatar

    A small image standing in for a person or entity, falling back to initials or a generic glyph when there is no picture.

  • Avatar groupalso avatar stack, face pile, facepile, stacked avatars

    Several avatars overlapped in a row to show a set of people compactly, with a plus n counter standing for the rest.

  • Axisalso x-axis, y-axis, value axis, category axis

    The ruled edge of a chart that maps position to value: scale, ticks, and labels that make the marks readable as numbers.

  • Badgealso dock badge, app icon badge, notification badge, count badge, unread count, red dot

    A small marker attached to another element that carries a count or a status and is not interactive on its own.

  • Banneralso notification banner, scoped notification, global banner

    A prominent message strip, usually spanning the top of a page or section, that stays visible until the user dismisses or resolves it.

  • Blame viewalso git blame, annotate view, line history

    Each line of a file labelled with the change that last touched it, so the file answers who and when rather than what it says.

  • Bottom navigationalso tab bar, bottom tabs, bottom bar

    A bar of three to five top level destinations pinned to the bottom edge of a phone screen, with the current destination always marked.

  • Bottom sheetalso sheet, half sheet, modal sheet

    A surface anchored to the bottom edge that slides up over the content, often draggable between a peeked and an expanded height.

  • Breadcrumbsalso breadcrumb trail, breadcrumb, path bar, crumbs

    A trail of links showing the path from the top of a hierarchy down to the current page, with every level above it clickable on the way back up.

  • Bubble toolbaralso floating toolbar, bubble menu, medium editor toolbar, text selection popover, edit menu

    A small formatting bar that appears floating over a text selection and disappears when the selection is dropped.

  • Buttonalso push button, cta button, action button

    A control that runs an action when activated, labelled with the thing it does rather than with where it goes.

  • Button groupalso button bar, grouped buttons, btn-group

    Buttons set flush against each other so they read as one unit of related actions, usually with shared borders and rounded outer corners only.

  • Calendaralso month view, date grid, mini calendar

    A month grid of dates that can be read, navigated and selected from, whether standing alone or living inside a date field.

  • Calloutalso admonition, inline alert, message bar, inset text, flashbar

    A boxed note set into the flow of content to carry a warning, tip or aside, coloured by severity and staying put once shown.

  • CAPTCHAalso human verification, bot check, recaptcha, turnstile

    A challenge placed in a form to sort people from scripts, from distorted text to a single checkbox that watches how you got there.

  • Cardalso tile, panel, item card, product card, lockup

    A bounded surface holding a preview of one thing, usually an image, a title, some detail and one or two actions, that as a whole leads somewhere.

  • Carouselalso slideshow, image rotator

    A row of items shown a few at a time that advances by arrows, swipe or a timer, with the rest waiting off screen.

  • Cascaderalso cascading select, dependent dropdowns

    A select whose options open level by level, each choice narrowing the next, used for country then state then city style data.

  • Character counteralso character count, char limit counter, remaining characters

    The running count beside a text box showing how many characters are used, or how many remain, against a limit.

  • Chartalso graph, plot, data visualisation, dataviz

    A drawing of data in which position, length, angle or colour carries the numbers, chosen so the comparison a reader needs is the easiest one to see.

  • Chart annotationalso annotation layer, callout label, data annotation

    A note pinned onto the data itself: a callout, arrow, or highlighted span that tells the reader what to see in the chart.

  • Chart legendalso chart key, series legend

    The key beside a chart that decodes series colours and symbols into names, and the first thing direct labeling tries to delete.

  • Chat bubblealso message bubble, speech bubble, bubble, message

    A rounded container for one message in a conversation, aligned and coloured by who sent it, often with a tail toward the sender's side.

  • Checkboxalso tick box, check box, checkboxes

    A square control that turns one independent option on or off, used in sets where any number of the options may be chosen.

  • Chevronalso arrow indicator, chevron icon, angle bracket

    The small angle bracket used as a directional marker: down means this opens, right means this goes deeper, in breadcrumbs it means next level.

  • Chipalso pill, token

    A compact, rounded element holding one value, which can usually be selected, removed, or both.

  • Close buttonalso dismiss button, x button, close icon

    The small dismiss control in the corner of a dialog, banner or panel, drawn as an X and named Close rather than X.

  • Coach markalso coachmark, hotspot, beacon, tour step, spotlight tooltip

    A temporary message anchored to a control that teaches what it does, often chained into a numbered sequence across a screen.

  • Code editoralso code view, code block

    A text area specialised for code, with a gutter of line numbers, syntax colouring and a caret that understands indentation.

  • Color pickeralso color chooser, color input, color wheel picker, saturation field

    A control for choosing a colour, usually pairing a saturation and lightness field with a hue slider, an alpha slider and a text field for a value.

  • Color wellalso color swatch button, colour chip, color field

    The small filled square that shows the current colour and opens a colour picker when pressed.

  • Column resizeralso column divider, column grip, resize gripper

    The invisible strip on a column border that widens or narrows the column when dragged, and often fits the column to its content on double click.

  • Comboboxalso combo box, autocomplete

    A text input paired with a list of suggestions that narrows as you type, where the list can be navigated and chosen from with the keyboard.

  • Command palettealso command menu, omnibar, spotlight, quick open, launcher

    A keyboard-summoned overlay whose single search box finds and runs any command or destination in an application by name.

  • Comparison tablealso pricing table, feature matrix, plan comparison, spec table

    A table whose columns are options and whose rows are features, read across to decide between plans or products.

  • Complicationalso accessory, watch face widget

    A slot on a watch face filled with one live figure from an app, sized to be read in the second a wrist is raised.

  • Confirmation dialogalso confirm dialog, are you sure modal, destructive confirmation

    A modal that stops an action part way through to ask whether you meant it, naming the consequence in its confirm button rather than saying OK.

  • Contribution graphalso calendar heatmap, contribution calendar, activity grid, green squares

    A year of days as a grid of week columns, each cell shaded by how much happened that day, so a habit reads as a pattern instead of a number.

  • Copy buttonalso copy to clipboard, clipboard button, copy icon

    A small control beside a value that copies it to the clipboard and confirms by turning into a tick for a second or two.

  • Data gridalso editable grid, spreadsheet grid

    A spreadsheet-like table where individual cells take focus and can be edited, navigated cell by cell with the arrow keys.

  • Data tablealso table, index table, list view, grid

    A table built for working with data rather than reading it: sortable columns, selectable rows, and controls that act on the rows you select.

  • Date pickeralso calendar picker, date field, date input, datepicker

    A field that opens a small calendar so a date can be chosen by looking at the month rather than typing it.

  • Date range pickeralso range calendar, date range, check in check out picker

    A calendar that takes a start and an end date in one pass, highlighting the span between them as you move.

  • Description listalso descriptions, summary list, key-value pairs, data list, definition list, properties list

    Paired labels and values laid out as a list of facts about one thing, rather than as a table of many things.

  • Diff vieweralso diff view, side-by-side diff, unified diff, split diff, code diff

    The view that puts two versions of a text against each other, side by side or interleaved, marking every line added, removed or changed and aligning what did not.

  • Disclosurealso collapsible, show hide, expandable section, details, expander, disclosure control

    A single button that shows and hides one region of content, reporting its state through aria-expanded.

  • Disclosure trianglealso twisty, expander arrow, turner, dropdown caret, disclosure indicator

    The small triangle beside a tree item that points right when collapsed and down when open, rotating as it toggles.

  • Divideralso separator, rule, horizontal rule, hr

    A thin line separating groups of content, decorative when the grouping is already clear and semantic when it is the only cue.

  • Dockalso taskbar, app dock, launcher bar, shelf

    A persistent strip of application icons anchored to a screen edge, holding launchers, running apps and pinned items in one row.

  • Drag handlealso grip, grip dots, move handle, reorder handle

    The small gripped area, often drawn as rows of dots or lines, that marks where an item may be picked up and dragged.

  • Draweralso navigation drawer, side panel, side sheet

    A panel docked to one edge of the screen that slides in over the content, holding navigation or the details of the thing you selected.

  • Dropdownalso drop-down, dropdown menu

    The loose everyday word for any panel that opens downward from a trigger, whatever the panel holds and whatever the trigger does with it.

  • Emergency exit buttonalso exit this page, quick exit, safety exit, escape button

    A control that leaves the current page immediately for an unrelated site and tries to clear it from history, for readers who may be watched.

  • Emoji pickeralso emoji keyboard, emoji palette, emoji panel

    A searchable grid of emoji organised by category, with recent choices remembered and skin tone chosen once.

  • Error baralso confidence interval, uncertainty band, confidence band

    Whiskers on a mark showing the range a value could plausibly take, so a chart does not imply precision it does not have.

  • Error messagealso validation message, inline error, field error

    The line attached to a field that says what went wrong and what to do about it, announced to assistive technology the moment it appears.

  • Expandable rowalso row expansion, detail row, sub row, drawer row

    A table row that opens to reveal a detail panel beneath it, keeping the row in place instead of navigating away.

  • Eyedropperalso color picker tool, dropper, EyeDropper API, pipette

    A tool that turns the cursor into a sampler so a colour can be picked from anywhere on screen, usually with a magnified preview of the pixel under it.

  • Faceted filteralso filter panel, facets, collection select filter

    A panel of grouped checkboxes and ranges that narrows a result set, each option usually showing how many results it would leave.

  • Fieldsetalso field group, legend, form group, field set

    A group of related form controls sharing one question, with a legend that acts as the label for the whole group.

  • Figurealso figcaption, figure caption, captioned image

    An image, table or code block bound to its caption so the two travel together and can be referred to from the running text.

  • File attachmentalso file, attachment, download, document list, file card

    A row or card standing in for a file, showing its type, name and size, with the one action that file supports: download, open or remove.

  • File uploadalso file input, file picker, upload, file dropzone

    A control that takes files, by opening the system picker from a button or by accepting a drop into a marked area.

  • Filmstripalso thumbnail strip, thumbnail rail, gallery strip, image list

    A scrollable row of thumbnails beside a larger view, where picking one changes what the large view shows.

  • Flame graphalso flame chart, icicle graph, flamegraph

    Stacked bars where width is time spent and depth is call nesting, so the widest plateau rather than the tallest tower is the thing worth fixing.

  • Floating action buttonalso fab, extended fab, float button

    A round, raised button that hovers above the content in a fixed corner, carrying the one action the screen is most for.

  • Floating labelalso floating placeholder, animated label, shrinking label

    A label that sits inside an empty field and rises to the field's top edge when the field takes focus or holds a value.

  • Flowchartalso flow chart, diagram as code, process diagram, mermaid diagram

    A diagram of steps in boxes joined by arrows, read rather than operated, and now more often generated from a few lines of text than drawn by hand.

  • Formalso form layout, input form

    A grouping of controls a reader fills in and submits together, carrying the labels, validation and submit affordance for the whole set.

  • Gantt chartalso gantt, project timeline, resource timeline

    One row per task with a bar along a time axis, the bar showing when the work runs and lines between bars showing what waits for what.

  • Gaugealso dial gauge, speedometer chart, semi circle progress, radial gauge

    A dial style readout showing one value on an arc between a minimum and a maximum, borrowed from instrument panels.

  • Ghost buttonalso text button, tertiary button, subtle button, quiet button, borderless button

    A button with no fill and often no border until you hover it, sitting at the bottom of the emphasis ladder above a plain link.

  • Grabberalso drag indicator, pull tab, sheet handle, grabber bar, pill handle

    The short rounded bar drawn at the top of a bottom sheet to say the surface can be dragged.

  • Hamburger menualso doner menu, burger, hamburger button, nav toggle

    A button of three stacked horizontal lines that opens a site's main navigation, usually in a panel over the page.

  • Helper textalso hint text, field description, assistive text, supporting text

    The short line under a field that explains the format or constraint before anything goes wrong.

  • Hover cardalso hovercard, rich preview, profile preview

    A rich preview panel that appears on hover over a link or an avatar, summarising what is behind it.

  • HUD panelalso floating window, heads up display, tool palette, inspector palette

    A small dark translucent floating window of controls that hovers over content without taking it over, common in media and creative tools.

  • Iconalso symbol, pictogram

    A small graphic symbol standing for an action, object or idea, read at a glance and rarely safe to ship without a label.

  • Icon buttonalso action icon, glyph button, square button

    A button whose whole label is an icon, so it needs an accessible name and usually a tooltip to say what it does.

  • Identiconalso generative avatar, default avatar, generated avatar

    A generated default avatar derived deterministically from an identifier, so the same account always gets the same abstract pattern without uploading anything.

  • Imagealso picture, img, media

    An embedded picture, sized and cropped by the layout around it, carrying the alternative text that stands in when it cannot be seen.

  • Image comparison slideralso before after slider, image comparer, comparison slider, wipe slider, image compare

    Two images stacked with a draggable divider that wipes between them, used to show a before and an after in one frame.

  • Image wellalso image drop target, avatar upload

    An editable image view that shows its current picture and accepts a replacement dragged or pasted straight into it.

  • Inline editalso editable, click to edit, edit in place, inline editing

    Text that reads as plain content until you click it, at which point it becomes an input in the same place with save and cancel.

  • Input groupalso input addon, field addon, prefix and suffix, input group text

    A field welded to text, a button or a select at one or both ends, so the addon reads as part of the same control rather than as a neighbour.

  • Input maskalso masked input, format mask, pattern input

    A field that imposes a fixed shape as you type, inserting the slashes, spaces or brackets a phone number or card number needs.

  • Kebab menualso three-dot menu, vertical ellipsis

    A menu of secondary actions opened from a trigger of three vertically stacked dots, usually at the end of a row, card, or toolbar.

  • Keyboard keyalso keycap, key hint, keybinding hint, shortcut chip

    A key drawn as a small keycap in running text or a menu, so a shortcut reads as something you press rather than something you say.

  • Keyboard shortcuts dialogalso hotkeys dialog, shortcut cheat sheet, keyboard help, shortcuts overlay, keyboard shortcut overlay, shortcut cheatsheet, hotkey overlay, press ? for help

    The panel opened by pressing question mark that lists every shortcut in the application, grouped by area.

  • Knobalso dial, rotary control, angle slider, circular slider

    A round control turned by dragging in an arc, borrowed from hardware and mostly found in audio and creative tools.

  • Lightboxalso image viewer, media overlay, photo viewer, image preview

    An overlay that shows one image or video large over a dimmed page, with next and previous controls and a dismiss.

  • Linkalso hyperlink, anchor, text link

    A control that navigates somewhere, named for its destination, and carrying the browser affordances of a destination (open in new tab, copy address).

  • Listalso list group, lists and tables, unordered list, ordered list

    A vertical run of related items presented as a set, where the shared shape of every row is what tells a reader the rows belong together.

  • Listboxalso option list, list box, selection list

    An always visible list of options you choose from with the keyboard or pointer, without a popup or a text field.

  • Live activityalso ongoing activity, live notification

    A persistent, updating view of something in progress, shown in system places like a lock screen so a reader can follow it without opening the app.

  • Meatball menualso three dots menu, horizontal ellipsis menu, three horizontal dots

    An overflow menu whose trigger is three horizontal dots, usually sitting at the end of a row or a card.

  • Media controlsalso transport controls, player controls, playback controls, video controls

    The cluster of play, pause, skip, volume and fullscreen controls attached to a player, which usually hides itself while playing.

  • Mega menualso megamenu, flyout menu, mega dropdown, navigation panel

    A large navigation panel that drops from a top level item and shows many links at once, grouped into columns with headings.

  • Menu baralso menubar, application menu, main menu

    A permanent horizontal row of menu titles (File, Edit, View) whose menus open on click and then follow the pointer along the row.

  • Menu bar extraalso status item, system tray icon, notification area icon, menulet, tray icon

    A small application controlled item living in the system menu bar or tray, usually an icon that opens a compact panel of status and controls.

  • Menu buttonalso dropdown trigger, menu trigger, disclosure button

    A button whose only job is to open a menu, marked with aria-haspopup and usually drawn with a downward chevron.

  • Meteralso level indicator, capacity indicator, strength meter, usage bar

    A gauge of a known quantity within a known range, such as disk used or password strength, where the level is a fact rather than a task.

  • Minimapalso code minimap, overview ruler, document map, navigator

    A shrunken overview of a long document or canvas beside the scrollbar, with a box showing which part is currently on screen.

  • Modal dialogalso modal

    A window that opens over the page and takes control of it, so nothing behind can be used until the dialog is answered or dismissed.

  • Model selectoralso model picker, model switcher, engine selector

    The control in an assistant interface that picks which model answers, usually a menu carrying a short description of each option.

  • Multi selectalso multiselect, tag picker, multi combobox

    A select that accepts several values at once, usually showing the chosen ones as removable tokens inside the field.

  • Navigation baralso navbar, top navigation, site header, nav, global header, header

    The horizontal strip of primary destinations across the top of a site, usually holding the logo, the main sections and an account control.

  • Navigation menualso nav menu, nav list

    A menu of destinations rather than commands, where opening an item moves you somewhere instead of running an action.

  • Navigation railalso activity bar, icon rail, rail, icon sidebar, mini drawer

    A narrow vertical strip of top level destinations at the side of a screen, used at medium widths where a bottom bar is wasteful and a drawer is too heavy.

  • Node graphalso node-based editor, node editor, node-based UI, flow editor

    A canvas of boxes wired to each other by lines, where each box does one job and the wiring between them is the thing being built, rearranged by dragging.

  • Node portalso socket, node handle, connection point

    The typed stub on a node where a wire may land, coloured or shaped by what it accepts, so a connection that would make no sense refuses to complete.

  • Notification centeralso notification tray, activity center, notification drawer

    A panel collecting notifications that were missed or kept, usually opened from a bell with an unread count.

  • Ornamentalso window ornament

    A small panel of controls that floats just outside a window edge in visionOS, staying with the window without covering its contents.

  • Overflow menualso more menu, more actions

    A menu holding the actions that do not fit in the visible interface, opened from one compact trigger.

  • Page indicatoralso page control, carousel dots, pagination dots, slide indicators, position indicator

    The row of small dots under a carousel or onboarding screen showing how many pages there are and which one you are on.

  • Paginationalso pager, paging controls, page navigation

    The numbered row of page links under a long result set, with previous and next controls and usually an ellipsis where numbers are skipped.

  • Password reveal togglealso show password toggle, reveal password, password visibility toggle, unmask button, unmask password, eye icon, password input, password toggle field

    The control inside a password field, usually an eye or the word Show, that switches the characters between masked and readable.

  • PIN inputalso otp input, one time code field, verification code input, otp field, segmented code input, segmented input, one-time password field, digit entry view

    A row of single character boxes for a short code, where typing advances to the next box and pasting the whole code fills them all.

  • Playheadalso play head, position marker, needle

    The marker showing the current position in a timeline or track, which travels during playback and can be dragged to move it.

  • Popconfirmalso inline confirmation, confirm popover, are you sure popover

    A small confirmation bubble anchored to the control you just pressed, asking whether you meant it without opening a dialog over the page.

  • Popoveralso flyout

    A small surface anchored to the control that opened it, holding content or controls of its own, and dismissed by clicking away or pressing Escape.

  • Popover arrowalso tooltip arrow, beak, nub, tail, pointer

    The small triangle joining a popover or tooltip to the thing it belongs to, which flips and slides as the popover repositions.

  • Presence indicatoralso status dot, online indicator, presence badge, activity status

    The small coloured dot on an avatar reporting whether a person is available, away, busy or offline.

  • Progress baralso progress indicator, loading bar, progress

    A filling bar reporting how far along a task is, determinate when the end is known and indeterminate when it is not.

  • Progress ringalso progress circle, ring progress, circular progress, donut progress, activity ring

    A circular progress indicator that fills around a ring, often with the percentage in the middle.

  • Prompt inputalso composer, message composer, chat input, prompt box

    The composer at the bottom of an assistant interface: a growing text area with attachment, model and send controls attached to it.

  • Property filteralso query builder, filter builder, search syntax field, structured search

    A search field that builds structured queries from tokens, letting a reader filter by named properties with operators rather than free text.

  • Push notificationalso notification, system notification, remote notification, heads-up notification

    A system delivered message shown outside the app, on a lock screen or in a notification list, that has to earn the interruption it costs.

  • QR codealso qrcode, scan code, 2d barcode

    A square matrix barcode rendered in the interface to hand a link or credential to a phone camera.

  • Quick settings tilealso toggle tile, Control Center control

    A one tap button or toggle an app contributes to the system control surface, so one feature can be reached without opening the app.

  • Radial menualso pie menu, circular menu, wheel menu

    A menu whose items sit around the point of invocation, so a choice is made by direction and distance rather than by reading a list.

  • Radio groupalso radio buttons, option group

    A set of mutually exclusive options, each with its own label and control, exactly one of which can be chosen.

  • Range slideralso multi thumb slider, dual slider, price range slider, two handle slider

    A slider with two handles on one track that sets a lower and an upper bound, so the selection is an interval rather than a point.

  • Ratingalso star rating, rate, score input, rating indicator

    A row of stars or similar marks that both shows a score and, when interactive, takes one.

  • Reaction pickeralso reaction bar, quick reactions, emoji reactions, like button

    A small row of emoji that appears on hover or long press so a message can be answered without a reply.

  • Reference linealso threshold line, target line, goal line, benchmark line

    A line drawn at a meaningful value across a chart: a target, a threshold, an average, a before-and-after moment.

  • Relative timestampalso relative time, time ago, fuzzy timestamp, humanized time

    A time printed as a distance from now, two hours ago or in three days, updating itself and holding the exact time in its tooltip.

  • Resize handlealso size grip, grow box, resizer, corner grip, handlebar

    The small corner grip that lets you drag an element or window bigger and smaller, drawn as diagonal ridges on a textarea or window corner.

  • Ribbonalso ribbon bar, office ribbon, fluent ribbon

    A tall tabbed toolbar that replaces menus, grouping commands into labelled sections with the important ones drawn larger.

  • Rich text editoralso RTE, wysiwyg editor, markdown editor, editor

    An editing surface that shows formatting as it will appear rather than as markup, so what the writer sees is close to what readers get.

  • Rich text toolbaralso formatting toolbar, wysiwyg toolbar, editor toolbar, format bar

    The strip of formatting controls above or beside an editor, whose buttons report their state from wherever the caret sits.

  • Scheduleralso event calendar, time grid, week view, day view

    A grid of days crossed with hours where each event is a block in its own slot, so a week's free time is visible and an event is moved by dragging it.

  • Scope baralso search scope bar, search filters, search tabs

    The row of category buttons directly under a search field that narrows what the query searches, such as All, Mail, Files.

  • Scrollbaralso scroller, scroll bar, overlay scrollbar, scroll indicator, scroll area

    The bar beside a scrollable region whose thumb shows both how much content there is and where in it you are.

  • Scrubberalso seek bar, progress scrubber, timeline scrubber, transport slider

    The seek control of a media player: a track showing elapsed and buffered time with a playhead you drag to move through it.

  • Search fieldalso search box, searchbox, search bar, omnibox, search input, text filter

    A text input specialised for queries, with a magnifier, a clear control and often suggestions that appear as you type.

  • Segmented controlalso content switcher, segmented button

    A single control holding two to five mutually exclusive options side by side, with the current one shown as a filled segment.

  • Selectalso dropdown list, picker, select menu, pull down menu, native select

    A closed control that shows the current choice and opens a list of options when pressed, with no typing.

  • Selection cardalso radio card, checkbox card, tiles, choice card, option card, control card

    A radio or checkbox dressed as a card, where the whole tile is the target and the control itself is small or absent.

  • Share sheetalso activity view, share dialog, share menu, web share

    The system panel of destinations and actions for sending the current item elsewhere, populated by whatever apps are installed.

  • Show more togglealso read more, expandable text, spoiler, see more, truncate toggle

    The control at the end of clamped text that expands it to full length and, when honest, collapses it again.

  • Signature padalso signature capture, draw signature, sign here box

    A drawing area that captures a handwritten signature by pointer or touch, with a clear control and a baseline to sign on.

  • Slideralso range input, range control, track bar

    A control that sets a value by dragging a handle along a track, showing the whole range at once.

  • Sort indicatoralso sort arrow, sort caret, sort direction indicator

    The small arrow in a column header showing that the table is sorted by that column and in which direction.

  • Sparklinealso mini chart, inline chart, trend line, micro chart

    A tiny chart with no axes or labels, drawn inline at text size to show the shape of a trend beside the number it belongs to.

  • Speed dialalso fab menu, expanding fab, radial fab

    A floating action button that fans out into three to six smaller related actions when pressed or hovered.

  • Spinneralso throbber, inline loading, loading indicator, activity indicator

    An indeterminate loading indicator that shows work is happening without saying how much of it is left.

  • Split buttonalso split menu button, button dropdown, dropdown button, menu split button, combo button

    A two part control where the main area runs a default action and an attached arrow opens a menu of related alternatives.

  • Splitteralso window splitter, resizable, split panel, sash, grab handle

    The draggable bar between two panes that changes how much room each one gets, keyboard operable as a slider between limits.

  • Statalso statistic, metric card, kpi card, big number, scorecard

    A single number shown large with a label and often a change indicator, the unit a dashboard is built from.

  • Step indicatoralso steps, progress steps, wizard steps, progress tracker

    A row or column of numbered stages showing where you are in a multi step flow and what remains.

  • Stepperalso spin button, spinbutton, number input, quantity selector, input stepper
